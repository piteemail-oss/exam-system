# 个人轻量化多科目考试问答系统

一款面向个人用户的、轻量化的、支持多学科/多题库的考试与错题复习全栈系统，专为个人备考、知识巩固场景设计，无需复杂部署，开箱即用。

## 功能特性

- ✅ 多科目题库管理，支持单选/多选/判断三种题型
- ✅ 全自动判分系统，交卷即出成绩
- ✅ 错题自动整理，强化复习机制，支持斩题标记已掌握
- ✅ 响应式设计，完美适配PC端和移动端
- ✅ PWA支持，可添加到手机主屏幕，类原生App体验
- ✅ 单文件SQLite数据库，一键备份/恢复，数据安全迁移
- ✅ 支持离线使用，无网络也能刷题

## 快速开始

### 环境要求
- Python 3.8+
- Node.js 18+

### 1. 下载项目
下载本项目代码到本地。

### 2. 启动后端
```bash
cd backend
pip install -r requirements.txt
uvicorn main:app --host 0.0.0.0
```

后端服务将在 `http://localhost:8000` 启动，支持局域网内其他设备访问。

### 3. 启动前端
```bash
cd frontend
npm install
npm run dev
```

前端服务将在 `http://localhost:5173` 启动，打开该地址即可使用系统。

## 部署说明
- 开发环境：如上所述，直接启动前后端服务即可
- 生产环境：
  1. 前端执行 `npm run build` 打包静态文件
  2. 后端配置静态文件服务，指向前端打包后的dist目录
  3. 也可以使用反向代理工具将前后端服务部署到同一域名下

## 数据备份与迁移
整个系统的所有数据都存储在 `backend/exam.db` 这个单文件中，你只需要复制这个文件就可以完成：
- 数据备份：复制该文件到安全位置
- 数据迁移：在新环境中，替换该文件即可恢复所有数据
- 也可以在系统的「设置」页面，通过备份/恢复功能一键操作

## 批量导入题库
系统已支持 CSV / XLSX 批量导入题目。在 `设置` 页面中，可以上传题库文件预览导入结果，先校验错误，再确认提交。

### 导入流程
1. 点击 `设置` 页面中的“预览导入题库”按钮，选择 CSV 或 XLSX 文件。
2. 系统会解析并检查每一行数据，展示有效题目数量和错误行信息。
3. 预览后确认导入，可将有效题目写入数据库。
4. 若存在错误行，可导出错误行 CSV 进行修正后重新上传。
5. 可通过“下载导入模板”按钮获取标准导入模板。

> 如果用 Excel 直接打开 CSV 文件，建议通过“数据 - 从文本/CSV 导入”方式，并选择 UTF-8 编码；或者先下载模板后直接用记事本查看。

### 导入模板字段
- `category_name`：科目名称，若科目不存在则自动创建。
- `category_id`：可选，优先使用该科目 ID。若不填写，则按 `category_name` 匹配。
- `type`：题型，值为 `1`（单选）、`2`（多选）、`3`（判断）。
- `content`：题干。
- `option_A`：选项 A 文本。
- `option_B`：选项 B 文本。
- `option_C`：选项 C 文本。
- `option_D`：选项 D 文本。
- `option_E` / `option_F`：可选，多选题可填写。
- `correct_answer`：标准答案，单选/判断写 `A`；多选写 `A,C`。
- `analysis`：解析文本，可选。

### 模板示例说明
- 单选题：填写 `type=1`，`option_A`~`option_D`，`correct_answer=A`。
- 多选题：填写 `type=2`，`correct_answer=A,C`，可填写多个选项。
- 判断题：填写 `type=3`，只需填 `content` 和 `correct_answer=A` / `B`。
- `category_id` 与 `category_name` 任选其一，推荐优先填写 `category_name`。

示例 CSV 行：
`历史,,1,中国第一位皇帝是？,秦始皇,汉高祖,唐太宗,宋太祖,,,A,秦始皇统一六国`
- `analysis`：解析，可选

| category_name | type | content | option_A | option_B | option_C | option_D | correct_answer | analysis |
|---|---|---|---|---|---|---|---|---|
| 历史 | 1 | 中国第一位皇帝是？ | 秦始皇 | 汉高祖 | 唐太宗 | 宋太祖 | A | 秦始皇统一六国 |

| 行测 | 3 | “天下为公”正确吗？ | 对 | 错 | | | A | 这是正确说法 |

## 技术栈
- 前端：Vue3 + Vite + Tailwind CSS + Shadcn Vue + PWA
- 后端：FastAPI + SQLModel + SQLite
- 数据库：SQLite（单文件，无需额外部署）
