# 个人轻量化多科目考试问答系统

一款面向个人用户的、轻量化的、支持多学科/多题库的考试与错题复习工具，无需复杂部署，开箱即用。**纯前端 PWA，完全离线可用。**

## 功能特性

- ✅ 多科目题库管理，支持单选/多选/判断三种题型
- ✅ 普通刷题 + 错题强化 + 闪卡背诵三种模式
- ✅ 全自动判分，答错立即记入错题集
- ✅ 错题自动整理，强化复习，支持斩题标记已掌握
- ✅ 题目搜索、收藏、隐藏管理
- ✅ 夜间模式、答题音效
- ✅ CSV/XLSX 批量导入导出
- ✅ 响应式设计，完美适配 PC 和手机
- ✅ PWA 支持，可添加到手机主屏幕，完全离线使用
- ✅ 数据存储在浏览器本地 IndexedDB，无需服务器

## 快速开始

### 开发环境

```bash
cd frontend
npm install
npm run dev
```

浏览器打开 `http://localhost:5173` 即可使用。

### 部署到手机（推荐）

#### 方式一：Cloudflare Pages（免费，国内可访问）

1. 将代码推送到 GitHub
2. 登录 [Cloudflare Dashboard](https://dash.cloudflare.com/)
3. 进入 **Workers & Pages** → **创建** → **Pages** → 连接 GitHub 仓库
4. 构建设置：
   - **构建命令**：`cd frontend && npm install && npm run build`
   - **输出目录**：`frontend/dist`
5. 点击部署，完成后获得 `https://xxx.pages.dev` 地址
6. 手机浏览器打开该地址 → 添加到主屏幕 → 就像原生 App

#### 方式二：Vercel（免费）

1. 导入 GitHub 仓库到 [Vercel](https://vercel.com/)
2. 设置框架为 **Vite**，输出目录为 `frontend/dist`
3. 部署后获得 `https://xxx.vercel.app` 地址

#### 首次使用

1. 手机打开部署地址（需要联网加载一次）
2. 首页点击"预览导入题库"上传 CSV/Excel 文件
3. 或者去设置页"导入数据库"导入已有的 `exam.db` 文件
4. 之后完全断网也能使用

## 三种刷题模式

| 模式 | 说明 |
|---|---|
| **开始刷题** | 普通考试模式，逐题作答，交卷打分 |
| **错题强化** | 只做错题集中的题，答对自动移出 |
| **闪卡模式** | 看题干→点翻转看答案→标记记住/没记住，适合背诵 |

在首页每个科目卡片上点击 **"闪卡"** 按钮可切换闪卡模式，每个科目独立设置。

## 数据管理

所有数据存储在浏览器 IndexedDB 中，完全离线。

- **导入**：设置页 → CSV/XLSX 导入，或导入 `.db` 数据库文件
- **导出**：设置页 → 导出数据库（`.db` 文件），或按科目导出 CSV
- **备份**：定期导出 `.db` 文件保存即可

---

## 批量导入题库

### 导入流程
1. 首页或设置页点击"预览导入题库"，选择 CSV 或 XLSX 文件
2. 系统解析并展示：有效条数、错误行、题目预览
3. 有错误时可导出错误行 CSV 修正后重新上传
4. 确认导入后自动创建科目并写入题目

### 导入模板字段

| 字段 | 说明 |
|---|---|
| `category_name` | 科目名称，不存在则自动创建 |
| `type` | 1=单选，2=多选，3=判断 |
| `content` | 题干 |
| `option_A` ~ `option_F` | 选项内容 |
| `correct_answer` | 正确答案，单选写 `A`，多选写 `A,C` |
| `analysis` | 解析说明（可选） |

## 技术栈

- 前端：Vue 3 + Vite + Tailwind CSS + PWA
- 数据库：sql.js（SQLite 编译为 WebAssembly，浏览器内运行）
- 存储：IndexedDB 持久化
- Excel 解析：SheetJS (xlsx)
