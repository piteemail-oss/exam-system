# 个人考试问答系统

一款面向个人用户的、轻量化的、支持多科目/多题库的考试与错题复习工具。

**纯前端 PWA，完全离线可用，无需服务器。**

> 项目最初为 FastAPI + Vue 前后端架构，后改为 sql.js (SQLite WebAssembly) 纯前端方案，所有数据存储在浏览器 IndexedDB 中。

---

## 功能特性

### 刷题模式
- **开始刷题**：普通模式，逐题作答，确认选择即时反馈，交卷统一打分
- **错题强化**：只做错题集中的题，答对自动移出
- **闪卡背诵**：显示题干 → 点击翻转查看答案 → 标记记住/没记住，适合背诵类科目
- **正序/乱序**：每个科目可独立设置顺序练习或加权随机排列
- **题型筛选**：按题型（单选/多选/判断/简答）控制题目的显示与隐藏，隐藏的题目不会出现在刷题中

### 考试模式
- 自定义科目、时长、题数、普通/闪卡模式
- 倒计时器，支持暂停/继续
- 交卷后仍可浏览答卷，查看正确答案和解析
- 中途退出自动保存状态，回来可继续
- 闪卡模式标记后不可更改

### 题型支持
| 题型 | type | 答题方式 | 说明 |
|------|------|----------|------|
| 单选题 | 1 | 选项单选 | 选对得分 |
| 多选题 | 2 | 选项多选 | 全部选对才得分 |
| 判断题 | 3 | 对/错二选一 | 选项自动生成 |
| 简答题 | 4 | 闪卡模式 | 始终以闪卡形式呈现，自我评估记住/没记住 |

### 题库管理
- 科目卡片：显示总题数、错题数、正确率
- CSV / XLSX 批量导入（带预览和错误行导出）
- 按科目导出 CSV
- 题目搜索、收藏（⭐）
- 题型筛选（快速隐藏/显示指定题型）
- 数据库文件（`.db`）导入导出，完整备份

### 乱序权重算法

乱序模式下使用**指数时钟加权算法**（基于 FSRS 难度模型），确保每轮刷题不漏题、不偏题：

```
weight = max(0.2, 1.0 + unseen_bonus + error_weight - correct × 0.3)

unseen_bonus = seen_count === 0 ? 2.5 : 0        // 未见过 → 3.5 倍权重，绝对优先
error_weight: 答错 +1.0，答对 -0.5（2:1 比例）  // FSRS 难度更新模型
```

| 场景 | 新题 | 轮1 | 轮2 | 轮3 | 轮4 | 轮5 |
|------|------|-----|-----|-----|-----|-----|
| 全对 | 3.5 | 0.7 | 0.4 | 0.2 | 0.2 | 0.2 |
| 错1次→全对 | 3.5 | 3.0 | 1.7 | 0.9 | 0.2 | 0.2 |
| 错2次→全对 | 3.5 | 3.0 | 4.0 | 2.8 | 1.8 | 1.0 |

核心原则：**未见过的新题永远优先，错过的题缓慢消退，全对的题快速沉底**。错题的主力解决方案在错题集。

### 错题管理
- 答错自动加入错题集，记录连续错误次数
- 错题强化模式：只练错题，答对自动移出
- 斩题：手动确认掌握，从错题本移除
- 一键清除全部错题

### 体验优化
- 夜间模式切换
- 答题音效（答对/答错），可开关
- 手机端答题卡底部面板，半屏展开直连底部
- 键盘快捷键（A/B/C/D 选择，←→ 切换，Enter 下一题）
- 左右滑动切换题目
- PWA 支持，添加到手机主屏幕，类原生 App 体验

## 快速开始

### 开发环境

```bash
cd frontend
npm install
npm run dev
```

浏览器打开 `https://localhost:5173`（使用自签名 HTTPS 证书，首次需允许）。

### 部署到手机

推荐使用 Cloudflare Pages（免费，国内可访问）。

#### 1. 推送代码到 GitHub

```bash
git remote add origin https://github.com/你的用户名/仓库名.git
git push -u origin main
```

#### 2. 部署到 Cloudflare Pages

1. 登录 [Cloudflare Dashboard](https://dash.cloudflare.com/)
2. **Workers & Pages** → **创建** → **Pages** → **连接到 Git**
3. 授权 GitHub，选择仓库
4. 构建设置：

| 配置项 | 值 |
|---|---|
| 构建命令 | `cd frontend && npm install && npm run build` |
| 输出目录 | `frontend/dist` |

5. 点击部署，获得 `https://xxx.pages.dev` 地址

#### 3. 手机使用

1. 手机浏览器打开部署地址（仅首次需联网加载）
2. 导入题库 CSV 文件或 `.db` 数据库
3. 添加到主屏幕
4. 之后完全离线可用

## 数据说明

所有数据存储在浏览器 IndexedDB 中，完全离线，不会丢失。

| 操作 | 路径 |
|------|------|
| 导入题库 | 首页或设置页 → 预览导入 → 选择 CSV/XLSX 文件 |
| 导出题库 | 设置页 → 选择科目 → 导出 CSV |
| 数据库备份 | 设置页 → 导出 `.db` 文件 |
| 数据库恢复 | 设置页 → 导入 `.db` 文件 |

## 导入模板

### 字段说明

| 字段 | 类型 | 说明 |
|---|---|---|
| `category_name` | 必填 | 科目名称，不存在则自动创建 |
| `category_id` | 选填 | 优先使用科目 ID，未填写时按 category_name 匹配 |
| `type` | 必填 | 1=单选，2=多选，3=判断，4=简答 |
| `content` | 必填 | 题干文本 |
| `option_A` ~ `option_F` | 选填 | 选项内容。多选题可填写多个选项，判断题填正确和错误两个选型，简答题在 option_A 填写答案 |
| `correct_answer` | 必填 | 标准答案，单选/判断/简答写 `A`，多选写 `A,C` |
| `analysis` | 选填 | 解析说明 |

### 示例

| 题型 | CSV 行 |
|------|--------|
| 单选 | `历史,1,中国第一位皇帝是？,秦始皇,汉高祖,唐太宗,宋太祖,,,,A,秦始皇统一六国` |
| 多选 | `政治,2,以下哪些是基本经济制度？,公有制,私有制,计划经济,市场经济,,,A,B,D,多种所有制经济共同发展` |
| 判断 | `行测,3,"天下为公"正确吗？,对,错,,,,,A,这是正确说法` |
| 简答 | `历史,4,简述秦始皇统一六国的意义。,结束了长期分裂割据，建立了中国历史上第一个统一的多民族中央集权国家。,,,,,,A,从政治、经济、文化三方面作答` |

## 数据库表结构

全系统仅使用单个 SQLite 数据库（通过 sql.js 在浏览器中运行），主要包含以下表：

| 表 | 用途 |
|---|---|
| `category` | 科目分类 |
| `question` | 题目（含 hidden/favorite/correct_count/seen_count/error_weight） |
| `wrongquestion` | 错题记录（独立表，答对即删） |
| `examrecord` | 考试历史记录 |
