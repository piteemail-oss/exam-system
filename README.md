# 个人考试问答系统

一款面向个人用户的、轻量化的、支持多学科的考试与错题复习工具。**纯前端 PWA，完全离线可用，无需服务器。**

---

## 功能特性

### 刷题模式
- **开始刷题**：普通模式，逐题作答，交卷打分，答错即时记入错题集
- **错题强化**：只做错题集中的题，答对自动移出
- **闪卡背诵**：显示题干 → 点击翻转查看答案 → 标记记住/没记住，适合背诵类科目

### 考试模式
- 自定义科目、时长、题数、普通/闪卡模式
- 倒计时器，支持暂停/继续
- 交卷后仍可浏览答卷，查看正确答案和解析
- 中途退出自动保存状态，回来可继续
- 闪卡模式标记后不可更改，仅交卷时写入错题

### 题库管理
- 支持单选、多选、判断、简答四种题型
- CSV / XLSX 批量导入导出
- 数据库文件（`.db`）导入导出，完整备份
- 题目搜索、收藏（⭐）、隐藏管理
- 科目独立设置闪卡模式

### 体验优化
- 夜间模式，暗色主题护眼
- 答题音效，可开关
- 手机端答题卡网格视图，一目了然
- PWA 支持，添加到手机主屏幕，类原生 App 体验

## 快速开始

### 开发环境

```bash
cd frontend
npm install
npm run dev
```

浏览器打开 `http://localhost:5173`。

### 部署到手机

推荐使用 Cloudflare Pages（免费，国内可访问）。

#### 1. 推送代码到 GitHub

在 GitHub 创建仓库后：

```bash
git remote add origin https://github.com/你的用户名/仓库名.git
git push -u origin main
```

#### 2. 部署到 Cloudflare Pages

1. 登录 [Cloudflare Dashboard](https://dash.cloudflare.com/)
2. **Workers & Pages** → **创建** → **Pages** → **连接到 Git**
3. 授权 GitHub，选择仓库
4. 构建设置：

| 配置项 | 值 |
|---|---|
| 构建命令 | `cd frontend && npm install && npm run build` |
| 输出目录 | `frontend/dist` |

5. 点击部署，获得 `https://xxx.pages.dev` 地址

#### 3. 手机使用

1. 手机浏览器打开部署地址（仅首次需联网加载）
2. 导入题库 CSV 文件或 `.db` 数据库
3. 添加到主屏幕
4. 之后完全离线可用

## 数据说明

所有数据存储在浏览器 IndexedDB 中，完全离线，不会丢失。

- **导入题库**：首页或设置页 → 预览导入 → 选择 CSV/XLSX 文件
- **导出题库**：设置页 → 选择科目 → 导出 CSV
- **数据库备份**：设置页 → 导出 `.db` 文件
- **数据库恢复**：设置页 → 导入 `.db` 文件

## 导入模板

### 字段说明

| 字段 | 类型 | 说明 |
|---|---|---|
| `category_name` | 必填 | 科目名称，不存在则自动创建 |
| `type` | 必填 | 1=单选，2=多选，3=判断，4=简答 |
| `content` | 必填 | 题干文本 |
| `option_A` ~ `option_F` | 选填 | 选项内容，判断题填正确和错误两个选型，简答题在 option_A 填写答案 |
| `correct_answer` | 必填 | 正确答案，单选/判断/简答写 `A`，多选写 `A,C` |
| `analysis` | 选填 | 解析说明 |
| `category_id` | 选填 | 优先使用科目 ID |

### 示例

| 题型 | CSV 行 |
|------|--------|
| 单选 | `历史,1,中国第一位皇帝是？,秦始皇,汉高祖,唐太宗,宋太祖,,,,A,秦始皇统一六国` |
| 多选 | `政治,2,以下哪些是基本经济制度？,公有制,私有制,计划经济,市场经济,,,A,B,D,多种所有制经济共同发展` |
| 判断 | `行测,3,"天下为公"正确吗？,对,错,,,,,A,这是正确说法` |
| 简答 | `历史,4,简述秦始皇统一六国的意义。,结束了长期分裂割据，建立了中国历史上第一个统一的多民族中央集权国家。,,,,,,A,从政治、经济、文化三方面作答` |
